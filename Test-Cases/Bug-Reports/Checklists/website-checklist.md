# Website Testing Checklist

---

# Login Page Checklist

- Verify email field is displayed
- Verify password field is displayed
- Verify Login button is clickable
- Verify password field hides characters
- Verify login with valid credentials
- Verify login with invalid password
- Verify validation messages for empty fields
- Verify invalid email format validation
- Verify "Forgot Password" link works
- Verify page responsiveness on mobile devices

---

# Registration Form Checklist

- Verify all required fields are present
- Verify successful registration with valid data
- Verify email validation
- Verify password length validation
- Verify password confirmation works
- Verify error messages are displayed correctly
- Verify duplicate email registration handling
- Verify registration button functionality
- Verify mobile responsiveness

---

# Shopping Cart Checklist

- Verify products can be added to cart
- Verify products can be removed from cart
- Verify product quantity can be updated
- Verify cart total updates correctly
- Verify cart persists after page refresh
- Verify checkout button works correctly

---

# Checkout Checklist

- Verify shipping form validation
- Verify payment form validation
- Verify successful order placement
- Verify order confirmation page appears
- Verify failed payment handling
- Verify mobile responsiveness during checkout

---

# UI Testing Checklist

- Verify buttons are aligned properly
- Verify text readability
- Verify images load correctly
- Verify no overlapping elements
- Verify responsive design on different screen sizes
- Verify navigation menu functionality

---

# Browser Compatibility Checklist

- Verify website functionality in Chrome
- Verify website functionality in Firefox
- Verify website functionality in Safari
- Verify website functionality in Edge

---

# Mobile Testing Checklist

- Verify touch elements are responsive
- Verify text is readable on small screens
- Verify scrolling works correctly
- Verify no layout breaking on mobile devices
- Verify forms work correctly on mobile
